# Mieter Guide – Lange Str. 5

## Ziel
Digitale Infoseite für Mieter (OG & EG Wohnungen)

## Struktur
- /        → Startseite
- /og      → Wohnung Obergeschoss
- /eg      → Wohnung Erdgeschoss

## Inhalte
- WLAN (nicht öffentlich!)
- Check-in Infos
- Hausregeln
- Geräte
- Kontakt
- Öffentliche Verkehrsmittel
- Einkaufsmöglichkeiten
    - Standort Lange-Str. 5, 71640 Ludwigsburg
    - Bäcker
    - Metzger
    - Discounter
    - Anzeige in einer Map wo Haus und alle relevanten Möglichkeiten angezeigt werden
- Sehenswürdigkeiten

## Anforderungen
- Mehrsprachig (DE / EN / FR / JA / CN)
- Mobile First
- QR-Code Nutzung vor Ort

## Sicherheit
- WLAN nicht öffentlich anzeigen
- ggf. Passwortschutz für sensible Daten

- Vercel (Auto Deploy via GitHub)

## Testing
